# IQ Components 
🚀 An enterprise-grade secondary UI component library based on **Vue 3** and **Element Plus**.

Designed to solve pain points in the development of enterprise-level applications, IQ Components provides a set of high-quality, high-performance, and easy-to-use components that can help developers quickly build modern, responsive, and user-friendly web applications.

## ✨ Features
- Enhanced core components (form, table, select, calendar, date picker etc)with additional features and functionalities.
- Custmized theme and language support.
- More than element plus components(card, collapse, step progress, etc).
- build with Vue and vite, easy to use and integrate.

## 📂 Components
| Component | Description | Type |
| :--- | :--- | :--- |
| iCard | card wrapper for content display | Custom |
| iCollapse | wrapper with collapse function | Custom |
| iConfigProvider | global configuration of components | Custom |
| iDrawer | enhanced drawer with extral functions: fullscreen, standard footer area | Enhanced |
| iDialog | enhanced dialog with extral functions: unify style, standard footer area, defaulf confirm/cancel click functions | Enhanced |
| iCalendar | enhanced calendar with custom content rendering, event markers and Kalendar Woche | Enhanced |
| iDatePicker | enhanced date picker with Kalendar Woche | Enhanced |
| iLayout | standard layout for a normal enterprise-level page withe query and table area  | Custom |
| iForm | enhanced configurized form | Enhanced |
| iSelectUser | user selection for specific enterprise scenario | Enhanced |
| iSelectDept | department selection for specific enterprise scenarios | Enhanced |
| iStepProgress | step progress bar  | Custom |
| iTable | enhanced table with inline search, pagination, drag and sort | Enhances |
